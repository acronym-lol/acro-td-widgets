# Contributing

This repo is a copy of `modules/acro-td-widgets/` in [acro-td-core](https://github.com/acronym-lol/acro-td-core), which maintainers update with `git subtree push`. Pull requests can't be merged here.

- **Code changes:** open a pull request on acro-td-core against its `dev` branch, editing the files under `modules/acro-td-widgets/`. See [acro-td-core's CONTRIBUTING.md](https://github.com/acronym-lol/acro-td-core/blob/main/CONTRIBUTING.md).
- **Issues** are welcome here.
